# Reglas para agentes de IA

Este repositorio es un prototipo educativo. El objetivo es avanzar rápido sin perder comprensión ni mantenibilidad.

1. Antes de editar, inspecciona el repositorio y `PROJECT.md`.
2. Convierte la intención del estudiante en el cambio mínimo verificable.
3. No agregues frameworks, dependencias o abstracciones sin una necesidad concreta.
4. Mantén los cambios pequeños y fáciles de revertir.
5. No ocultes errores: explica causa, cambio y evidencia.
6. Después de modificar código, ejecuta `npm run build`.
7. Si una solución empieza a crecer, señala deuda técnica antes de expandirla.
8. El estudiante decide producto, estética y prioridades. El agente implementa, explica y audita.

Al terminar responde con:
- Resultado
- Archivos cambiados
- Verificación realizada
- Deuda o riesgos encontrados
- Siguiente movimiento opcional
