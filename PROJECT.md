# Proyecto

## Idea en una frase
Shooter 3D en primera persona estilo arena: sobrevive en el interior de una nave mientras eliminas enemigos; a los 40 segundos aparece un jefe final y, al derrotarlo, una puerta conduce a la siguiente cámara de la campaña.

## Prototipo mínimo
Jugador en primera persona con WASD, salto y mira con el ratón (PointerLock), tres armas (pistola, AK, cuchillo), enemigos que persiguen, atacan y colisionan con el escenario y entre sí, campaña de 5 cámaras con decorado y paleta propios, HUD con vida, resistencia y arma.

## Criterio de terminado actual
- [x] Se puede ejecutar con `npm run dev`.
- [x] Hay una acción del jugador (moverse, saltar, disparar, cambiar de arma).
- [x] El juego responde de forma visible a esa acción (daño, partículas, HUD).
- [x] El jugador y los enemigos no atraviesan muros, props ni entre sí.
- [x] Al derrotar al jefe se abre una puerta y cruzar avanza de cámara.
- [x] Cada cámara tiene texturas, paleta y decorado propios.
- [x] `npm run build` termina sin errores.
