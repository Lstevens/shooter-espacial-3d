# Proyecto

## Idea en una frase
Shooter 3D en primera persona estilo arena: sobrevive 60 segundos en un escenario cerrado mientras eliminas enemigos; a los 40 segundos aparece un jefe final.

## Prototipo mínimo
Un cubo controlable con WASD y mira con el ratón (PointerLock), con tres armas (pistola, AK, cuchillo), enemigos que persiguen y atacan al jugador, HUD con vida, tiempo y arma. Es un prototipo completo jugable.

## Criterio de terminado actual
- [x] Se puede ejecutar con `npm run dev`.
- [x] Hay una acción del jugador (moverse, disparar, cambiar de arma).
- [x] El juego responde de forma visible a esa acción (daño, partículas, HUD).
- [x] `npm run build` termina sin errores.
