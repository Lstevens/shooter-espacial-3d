# Shooter 3D Arena

Prototipo educativo de shooter 3D en primera persona — Three.js + Vite + arquitectura modular.

## Inicio Rapido

```bash
# 1. Instala dependencias
npm install

# 2. Desarrollo (hot-reload)
npm run dev
# Abre http://localhost:5173 y haz clic en el canvas para PointerLock

# 3. Produccion
npm run build && npm run preview

# 4. Documentacion web
npm run docs:dev
```

## Controles

| Accion | Tecla / Input |
|--------|---------------|
| Moverse | `W` `A` `S` `D` |
| Apuntar | Raton (PointerLock) |
| Disparar | Clic izquierdo |
| Cambiar arma | `1` `2` `3` / Rueda raton |
| Recargar | `R` |
| Saltar | `Espacio` |
| Guardar campana | `F5` |
| Pausar / Menu | `Esc` (suelta PointerLock) |

**Armas**: Pistola (hitscan) · AK (automatica) · Cuchillo (melee)
